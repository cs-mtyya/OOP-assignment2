SimulatorUI "1" *-- "1" CPU : creates and manages
SimulatorUI "1" *-- "1" Memory : creates and manages
CPU "1" *-- "1" RegisterFile
CPU "1" *-- "1" ALU

CPU ..> Instruction : decodes into

CPU ..> HexUtils : uses
ALU ..> HexUtils : uses
SimulatorUI ..> HexUtils : uses

note right of Memory
  256 bytes of main RAM.
  Address FF is mapped to screen output:
  writing to FF displays the value.
  reset() clears all cells.
end note

note right of RegisterFile
  16 general-purpose registers (R0-RF)
  reset() clears all registers.
end note

note right of CPU
  fetch(): reads 2 bytes into IR, updates PC
  decode(): parses the 4-digit hex instruction
  execute(): performs the instruction logic
  reset(): clears PC and IR for a restart
end note

note bottom of SimulatorUI
  loadProgramFile() parses the program file
  (e.g. 21AA, 31A0, ... C000) and ignores
  comments and empty lines
end note
